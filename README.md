# SproutMe Capstone

## Project Summary

### One-sentence description

Our capstone team contributes to SproutMe, a marketing platform that helps agencies and businesses connect their accounts, track ad performance, and share reports.

### Additional information

Seth Aguilar, Warren Christian, Quinnlan McCarthy, and Itay Shemesh work on individual assignments from SproutMe's private Jira board. We use regular client standups to review progress, clarify requirements, and pick up new work. This repository contains our course-facing sprint reports and presentations.

## Installation

### Prerequisites

Use a Markdown viewer or GitHub to read the reports and a PowerPoint-compatible viewer to open the slide decks. A browser is needed to watch the demo videos. Git is optional for a local copy.

### Add-ons

The course repository has no application dependencies or seed data. The product work documented here includes Sanity for website content, Slack for account integration, and Google and Meta account connections in Competitor Skills. The Shopify integration was still in development at the Sprint 2 snapshot.

### Installation Steps

1. Open this repository on GitHub, or use **Code → Download ZIP** and extract it to browse locally.
2. Open a sprint report or presentation from [Additional Documentation](#additional-documentation).
3. Use the linked demo video to see the product UI.

Running the SproutMe application requires authorized access to the private product repository and development environment. SproutMe provides setup and test-data instructions through its internal channels.

## Functionality

- **Onboarding.** The team completed changes to the onboarding flow and continued work on self-serve onboarding and billing.
- **Ad metrics reports.** The report's download button generates a PDF on the server. The team refined the PDF layout, and the export was in Human Testing at the Sprint 2 snapshot.
- **Integrations.** The Slack integration reached Human Testing. The team also added Google and Meta account connections to the Competitor Skills section.
- **Website content.** The team used Sanity to manage skills and author content and added pagination to the author and blog pages. The author page was in Human Testing.

## Known Problems

At the Sprint 2 snapshot, the Shopify integration was about halfway complete. Self-serve onboarding needed revisions, and account-picker polish and account hierarchy work were queued. The [Sprint 2 report](Sprints/Sprint_2/Sprint_Report/SproutMe-Sprint-2-Report.md) lists the remaining work and testing status. Product defect details and reproduction steps are kept in SproutMe's private Jira project.

## Contributing

For course documentation changes, create a branch and open a pull request in this repository. Put sprint reports in `Sprints/Sprint_N/Sprint_Report/` and slide decks in `Sprints/Sprint_N/PPT/`. Update this README each sprint with current progress and links to the latest materials.

Product changes go through SproutMe's private Jira and pull request workflow. Course submissions can show the product UI and summarize the team's work under the SproutMe NDA.
